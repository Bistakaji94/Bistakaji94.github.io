# CMS-Ready Personal Website

All editable website content is stored in one file:

content/data.json

## Editing dashboard
Open:

https://bistakaji94.github.io/admin/

Sign in with your GitHub token, edit content, then publish.
GitHub Pages will update the live website automatically.

## Central personal information
Use:

Website Content → Personal Information

Changing your name, email, location, portrait, homepage text, or social links updates them across all pages automatically.

## Content sections
- Research Projects
- Field Notes and Blog
- Vlogs and Videos
- Photo Albums

Every image has an editable caption.

backend:

## Upload
Upload every file and folder in this package directly to the root of your GitHub Pages repository.
Delete the old content/research, content/posts, content/videos, and content/gallery folders from the previous version.
